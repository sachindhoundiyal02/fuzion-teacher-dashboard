Connect to Live Firebase

This dashboard contains real Firebase Auth and Firestore code. Currently, it is running in Demo mode using your web browser's local storage.

Steps to connect live database:
  1. Go to Firebase Console and create a new project.
  2. Enable Email/Password Authentication in Build > Authentication.
  3. Enable Cloud Firestore and configure database rules to allow read/write access.
  4. Create a Web Application configuration under Project Settings.
  5. Open the file firebase-config.js inside your project directory.
  6. Replace the placeholders in the firebaseConfig object with your real application credentials.
Once config is updated, refresh any page. The app will automatically connect to your cloud database!
